3. BUGS FOUND (AUDIT SUMMARY)
--------------------------------------------------------------------------------
A pre-flight audit of all 47+ source files identified 9 actionable bugs/vulnerabilities:
  1. BUG-1 (CRITICAL): AttributeError in src/translation/translator.py line 199.
     `detection = self.detector.detect(text)` returns a DetectionResult dataclass instance, but
     the code attempted dictionary lookup `detection.get("status")` and `.get("language_code")`.
  2. BUG-2 (CRITICAL): Deceptive/Fabricated Pipeline Execution Trace in src/app.py.
     Lines 514-536 hard-coded green checkmarks stating evidence retrieval, NLI inference, and
     temporal reasoning completed, even for inputs failing early (e.g. blank images or empty text).
  3. BUG-3 (CRITICAL): Biased Verdict Aggregation in src/pipeline/pipeline.py line 430.
     `if VERDICT_VERIFIED in verdicts and VERDICT_UNVERIFIED in verdicts: return VERDICT_VERIFIED`
     caused documents with unverified claims to be falsely certified as overall VERIFIED.
  4. BUG-4 (CRITICAL): Hard-coded temporal reference year in src/evidence_fusion/fusion.py line 150.
     `current_ref_year = 2024` hard-coded; in 2026, valid recent news was artificially penalized.
  5. BUG-5 (MODERATE): Unhandled exceptions during translation model loading and token generation
     in src/translation/translator.py. Network drops or OOM crashed the entire pipeline.
  6. BUG-6 (MODERATE): Unhandled exceptions during NLI model inference in src/nli/nli_model.py.
     Hugging Face tokenization exceptions or out-of-memory errors crashed the entire pipeline.
  7. BUG-7 (MODERATE): Domain spoofing vulnerability in src/evidence_retrieval/source_reliability.py.
     `pat in full_url` allowed query parameters (e.g., `https://untrusted.org/?ref=who.int`) to match Tier 1.
  8. BUG-8 (MODERATE): Dataclass/dict schema incompatibility in EvidenceQualityAnalyzer and EvidenceFusionEngine.
     Retrieval returns EvidenceItem dataclasses; methods calling `.get()` crashed with AttributeError.
  9. BUG-9 (SECURITY/HYGIENE): Missing root `.gitignore` file, risking accidental tracking of `.env` secrets.

4. BUGS FIXED
--------------------------------------------------------------------------------
All 9 identified bugs were resolved directly in the codebase:
  1. FIX-1: Updated translator.py to use `detection.status` and `detection.language_code` attribute access.
  2. FIX-2: Refactored app.py execution trace to dynamically check actual stage status flags from PipelineResult.
  3. FIX-3: Updated pipeline.py verdict aggregation to return UNVERIFIED when VERIFIED and UNVERIFIED claims coexist.
  4. FIX-4: Replaced hardcoded `2024` with `datetime.now().year` in fusion.py.
  5. FIX-5: Wrapped translator.py model loading and sequence generation in try/except; returns status='failed' on error.
  6. FIX-6: Wrapped nli_model.py pipeline execution in try/except; returns NEUTRAL with score 0.0 on error.
  7. FIX-7: Replaced `pat in full_url` with strict domain parsing and path-prefix matching in source_reliability.py.
  8. FIX-8: Added `_get_item_val` / `_get` helper in fusion.py and evidence_quality.py to handle both dicts and dataclasses.
  9. FIX-9: Created root `.gitignore` strictly excluding `.env`, `venv/`, `__pycache__/`, models, and temporary files.
 10. TEST-FIX: Made test_hindi_translation in tests/test_translation.py robust to model phrasing variations.
